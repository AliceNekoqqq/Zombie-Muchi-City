## v1.11.0 父母暗线弱提示
- 父母仍然不是任务系统的一部分：不创建任务条、地图标点、结构化 `side_clue` 或固定导航目标。
- 仅在暮迟市频道随机抽中“寻人启事”人味插播，且剧情处于灾变 Day 1~Day 8、父母仍未被玩家实际找到时，才可能给生成模型一个匿名模糊提示候选。
- 提示随时间段变化：旧街事故后的中年夫妻目击、槐安公寓附近寻找高三女儿的邻里转述、旧街仓房附近的断续求救。广播不会直接确认他们就是玩家父母。
- Day 9 起停止主动广播父母提示；若玩家错过营救窗口，死亡真相只能通过后续实际探索发现。
- 这些人味提示永远不能单独更新地图情报，也不会推进父母暗线状态。

## 生成 API
- 默认状态改为 **未配置**：首次使用不会自动借用酒馆主预设。
- 未配置时，自动广播直接跳过，不会偷偷发起模型请求。
- 手动点击“接收新播报”或“重Roll”时，会提示先进入“生成 API”设置。
- 可选生成来源：未配置 / 主预设 / 代理预设 / 独立 API。

## 设置跨角色卡 / 跨聊天保存
- MR-87 的用户设置保存在酒馆主页面的浏览器 `localStorage`，同一浏览器与同一酒馆站点下切换角色卡、聊天后继续沿用。
- 保存内容包括：生成来源、代理预设选择、模型覆盖、独立 API 配置、自动接收、内容随机性、剧情联动、显示等设置。
- **广播历史、每日区域情报、导演连续事件等剧情状态仍保存在当前剧情的脚本变量中**，不会串到别的角色卡或聊天。
- 独立 API Key 只有勾选“在本机保存 Key（跨角色 / 对话）”时才写入本地；未勾选时只在当前脚本会话内使用。
- 如果运行环境禁止 `localStorage`，脚本会退回当前剧情的脚本变量保存设置，并在设置界面提示无法跨卡持久化。

## 代理预设详情
选择酒馆中的代理预设后，会立即显示：
- 当前代理预设名称
- 连接来源（URL / Key 由酒馆代理预设托管）
- 当前模型策略（跟随预设 / MR-87 覆盖模型）
- 当前采样策略（跟随预设 / MR-87 自定义温度）

酒馆助手公开接口目前只提供代理预设名称与生成时的 `proxy_preset` 选择，不返回代理预设保存的 URL / Key 明文，因此 MR-87 不伪造或抓取未公开的敏感连接内容。

## 独立 API 预设
独立 API 页面新增本地预设管理：
- 保存 / 覆盖预设
- 载入预设
- 删除预设
- 保存 API 类型、URL、模型、采样设置；Key 是否保存由“在本机保存 Key”单独控制。
- 预设同样保存在浏览器本地，可跨角色卡 / 跨聊天使用。
