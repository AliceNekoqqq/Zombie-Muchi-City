# MR-87 v1.6.0 · 废墟电波 UI 重构

本版保持 v1.5.0 的生成逻辑、取消请求、多频道单请求、每日地图情报、重Roll、事件导演等功能不变，主要重构 MR-87 的视觉与信息层级。

## v1.6.0

- 使用 `Assets/MR87_backdrop.png` 作为展开态氛围背景：暮迟市废墟、旧收音机、手写便笺与暖灯共同构成“还有人在说话”的末日广播空间。
- 主界面由“仿硬件白色面板”改成深色半透明玻璃 + 旧金属 + 暖琥珀 / 低饱和青绿信号色，减少刻板的粉色女性化表达。
- 桌面端重构为“频段侧栏 + 当前播报主区”：左侧保留实体收音机感，右侧聚焦正文、手动拉取、调频、地图情报与快捷操作。
- 折叠态同步改为更轻的广播条，仍能快速查看频道、标题、摘要、信号和时间。
- 设置页同步换成同一套废墟电波视觉，并继续支持桌面标题拖动、移动端全屏布局。
- 所有原有功能 selector / data-action 保持不变，避免 UI 重构破坏生成、频道切换、取消、重Roll、日志与设置逻辑。

## 保留功能

- 全球 / 中国 / 暮迟多频道合并为一次请求。
- 手动选择本次拉取频道。
- 生成中可取消，180 秒安全超时。
- 主预设 / 代理预设 / 独立 API 与模型拉取。
- 每日地图情报、重Roll、事件导演、反重复、连续事件弧与人味插播。
