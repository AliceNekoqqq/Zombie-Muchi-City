# MR-87 v1.4.0

本版在 v1.3.0 的每日地图情报/重Roll基础上加入“广播事件导演”。

- 脚本先抽取频道事件主题、区域、稀有度、阶段、可靠度、播报形式、情绪、人味插播，再让模型写广播。
- 多样性：稳健 / 自然 / 丰富 / 混乱。
- 近期事件指纹降低重复权重；可选连续事件弧在 1-3 个游戏日内产生后续。
- 暮迟市可随机出现幸存者点歌、寻人、交换、宠物、生日、87报平安、黑色幽默、留言墙、旧广播残片、奇怪频段、午夜节目等。
- 人味插播与地图情报严格分层：点歌/玩梗等不能单独修改地图。
- 日结算后的普通广播仍使用纯广播请求；重Roll会恢复当日地图情报基线和导演基线，再抽取新的内容组合覆盖上一版。
- 点歌可写现实歌曲名/歌手和极短歌词摘录；不依赖外部搜索能力，也不会要求模型输出长段现实歌曲歌词。
