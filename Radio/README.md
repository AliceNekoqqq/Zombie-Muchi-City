# MR-87 v1.7.0 · 场景式界面重构

这一版不是旧布局换皮，而是完整重构主界面 DOM 与设置工作台布局。

- 主界面：三栏“频道 / 当前播报 / 情报与快捷入口”，手机端自动重排为单列。
- 背景图使用真实 `<img>` 节点挂载，不再依赖 CSS 相对路径，避免只看到黑底。
- 面板透明度重新设计，让竖版废墟电台背景真正参与画面。
- 当前播报成为视觉中心，手动拉取、地图情报和设备控制分层。
- 设置页改成左侧导航 + 右侧工作台，保留生成 API、模型拉取、自动接收、剧情联动等全部功能。
- 保留 v1.5.0/v1.6.0 的可取消请求、多频道合并请求、地图日结算、重Roll、事件导演、人味插播等功能。
