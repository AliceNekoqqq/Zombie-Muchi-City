# MR-87 v1.9.3 · 实体收音机结构重构

本版不再使用三栏网页仪表盘结构，主界面重构为单一“实体收音机机身”：顶部模拟调谐窗、左侧扬声器与频道预设、右侧广播玻璃屏、底部旋钮与实体按键。

关键修复：
- 移除三栏布局，避免 PC 中栏被压成细长列。
- 主界面高度压缩，背景图只作为场景，不再承担布局。
- 频道、接收、扫频、重Roll、记录、设置全部使用不透明实体按钮。
- 背景图亮度提高，场景通过机身四周和顶部明确露出。
- 手机保留收音机识别度，但隐藏大扬声器和底部硬件控制，避免过长。
- 安装新版本时会清理所有旧 `swz-radio-style*` 样式节点，避免 v1.7/v1.8 CSS 与新版本叠加。

功能逻辑保持：多频道合并请求、取消生成、每日地图情报、重Roll、事件导演、API 设置、模型拉取。

## v1.9.3 布局热修
- “本次拉取”改为两行控制面板：频道键与主接收键不再互相挤压。
- 底部硬件控制区加入最小列宽，5 个设备键不再被压成竖条。
- 新增 CSS Container Query：按 MR-87 自身宽度响应，而不是按浏览器 viewport 响应，适配 SillyTavern 窄聊天列。


## v1.9.3 背景与幸存者频段可读性
- 大机身/工作区改为透明或低透明，保留小模块为实体仪器，完整露出 MR87_backdrop 背景。
- 【幸存者频段】【点歌留言】【短讯】在广播听写中自动分成独立截获频段块，保留换行并提高识别度。
