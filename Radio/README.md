# 暮迟市 MR-87 末世收音机 v5.0.0

## 当前设计

v5.0.0 在正文顶部广播机制基础上重新设计界面；同时保留：**广播先生成并注入本轮正文上下文；视觉上以紧凑广播条出现在最新一条角色回复的正文最前面。**

有新广播时显示一条约一行半高的广播条；点击「展开」后才出现完整 MR-87 实体设备、频道、调频、历史和设置。没有新广播时默认不占正文空间。

## 生成顺序

支持酒馆助手 `GENERATION_AFTER_COMMANDS` 时：

```text
玩家发送
→ 判断是否需要广播
→ 后台 generateRaw 生成广播
→ 轻量事件/广播摘要写回当前 MVU
→ 用 injectPrompts(once:true) 把广播摘要注入即将生成的正文
→ 正文生成
→ 新回复顶部显示广播条
```

因此沈挽昼可以在同一轮自然地对刚收到的广播作出反应，而不是等下一轮才知道。

如果当前酒馆助手版本没有该事件，设备仍可手动接收并显示；更新酒馆助手后可获得完整的“广播先于正文”流程。

## 自动触发

默认只在以下情况尝试产生新广播：

- 本聊天还没有任何广播时的第一次正常生成；
- 跨日期；
- 地点发生变化；
- 世界时间累计经过设定小时数；
- 玩家手动点击「接收新播报」。

普通短对话不会每轮强制刷新广播。

## 三个频道

- 全球：2至7天信息延迟；国际感染、交通、公开医疗与人道信息。
- 中国：6至36小时延迟；跨区域交通、电网、公共卫生与救援。
- 暮迟市：数分钟至12小时延迟；道路、南桥、尸群、供水供电、天气、通信、避难点与普通幸存者消息。

## 固定世界事实

- 当前故事时间起点：2024-10-27 19:42。
- 稳定解药完成节点：2026-04-27 19:42，整整一年半后。
- 这个日期是世界事件约束，不是电台能提前知道的“预言”。
- 主角不是关键样本或救世主。
- 广播不知道沈挽昼特殊感染，也不知道 {{user}} 实时位置。
- 广播绝不泄露楚泽私人秘密、日记内容或其暗中行为。
- E-P原本是正规生物医学研究；广播只接触公开层面的事故、研究和医疗信息。

## 动态地图联动

只有暮迟市频道在消息确实代表城市态势变化时，才可附带一个轻量世界事件。一次最多影响3个已有地点，并使用克制的小幅变化：

- 尸群指数增减；
- 资源指数小幅增减；
- 通行状态；
- 动态标签。

广播不是每次都改变量。普通天气、生活通告、旧闻等大多数消息只提供信息。

## 失散同伴线索

本地广播可低概率成为林安安/陆斯年的**富余线索**，但只能是模糊公共信息，例如“年轻女性急救者”“学生频道断续呼叫”。脚本最多把支线推进到发现踪迹/锁定区域，不会靠一条广播直接确认最终房间或完成救援。

## MVU分工

完整广播历史留在脚本变量。MVU只保存：

- 当前频道；
- 信号状态；
- 上次刷新时间；
- 全球/中国/暮迟市三个频道各自最新摘要；
- 最近一个实际生效的本地世界事件。

这样不会让 `stat_data` 随广播历史不断膨胀。
